制作物と、開発の途中で調べたことを置いておく場所が欲しくてつくりました。

## 何を置くか

置くものは 3 つに絞りました。

- つくったもの(制作物)
- 開発中に詰まって調べたこと(記事)
- 自分がどういう人間か(自己紹介)

逆に、日記のような内容は置かないことにしました。読む人が知りたいのは「何をつくれるのか」であって、そこに集中したほうが伝わると考えたためです。

## なぜ Astro か

扱うのはほぼ静的なコンテンツなので、クライアントに JavaScript を送る必要がほとんどありません。Astro はデフォルトで JS を出力せず、必要なところにだけ足せます。記事一覧のタグ絞り込みだけは操作が要るので、そこにだけ小さなスクリプトを置いています。

Markdown をそのままコンテンツとして扱える点も決め手でした。記事を書いて push すれば公開される、という流れにしたかったからです。

## なぜ Cloudflare Workers か

静的アセットの配信が速く、個人サイトの規模なら無料枠で運用を続けられます。バックエンドを持たない構成にしたので、Workers 側でやることは実質アセットの配信だけです。
